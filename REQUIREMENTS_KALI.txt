DESCRIPCIÓN DEL NODO
────────────────────
Este nodo Kali Linux actúa como el agente ejecutor de ForceVector.
Se conecta al Servidor Windows via REST API / WebSocket + JWT para recibir
órdenes de reconocimiento, escaneo, explotación y post-explotación.
Toda la lógica de IA (LLM) y base de datos reside en el Servidor Windows;
el nodo Kali solo ejecuta las herramientas ofensivas de forma local.


================================================================================
1. SISTEMA OPERATIVO
================================================================================

  - Kali Linux 2024.x o superior (Rolling Release recomendado)
  - Arquitectura: x86_64 (amd64)
  - Entorno de virtualización: VMware Workstation Pro (recomendado)
  - RAM mínima para la VM: 4 GB (recomendados 8 GB)
  - Almacenamiento mínimo: 40 GB
  - Conectividad de red con el Servidor Windows (LAN o WireGuard VPN)

6. CONFIGURACIÓN DE RED
================================================================================

  - El nodo Kali debe tener acceso de red al Servidor Windows en los puertos:
    * TCP 11434  → Ollama API (LLM)
    * TCP 5432   → PostgreSQL
    * TCP 55552  → MSFRPC (solo localhost en Kali)

  - Verificar conectividad:
    nc -zv 192.168.159.1 11434
    nc -zv 192.168.159.1 5432

  - Configuración VPN (opcional):
    Si la VM no está en la misma LAN, usar WireGuard VPN para conectar
    el nodo Kali con el Servidor Windows de forma segura.

NOTAS ADICIONALES
================================================================================

  - El módulo 'readline' (historial de comandos en la CLI) está disponible
    de forma nativa en Linux; no requiere instalación adicional.

  - El módulo 'pty' (pseudo-terminal para sandboxes) es nativo de Python 3
    en Linux; no requiere instalación adicional.

  - WeasyPrint puede requerir dependencias adicionales según la distribución:
    sudo apt install -y libgdk-pixbuf2.0-dev libcairo2-dev

  - Si msfrpcd falla al iniciarse, intentar manualmente:
    sudo msfrpcd -P msf -p 55552 -a 127.0.0.1 -S -d

  - Los modelos LLM configurados (qwen3:14b) requieren VRAM suficiente
    en el Servidor Windows. Consultar README.md para alternativas.
